# Contribuer à HomeHub

Merci de votre intérêt ! HomeHub est un système personnel pour Android TV, piloté depuis le téléphone.

1. Lisez la [vision](docs/vision.md) et l'[architecture](docs/architecture.md) : la règle d'or est **« la TV affiche, le téléphone décide »**.
2. Ouvrez une issue avant un changement important, pour en discuter.
3. Suivez le [guide développeur](docs/developer-guide.md) : une branche par sujet, Conventional Commits, pull request avec le modèle fourni, CI verte obligatoire.
4. Toute décision structurante passe par une [ADR](docs/adr/README.md) ; toute modification du protocole met à jour [l'API locale](docs/api/local-api.md).

En contribuant, vous acceptez que votre code soit publié sous [licence MIT](LICENSE).
